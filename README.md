# Array & String Lab

A LeetCode-inspired learning and practice web app for Python DSA beginners.

## Features
- 24 curated Array and String problems from Easy to Hard
- Problem descriptions, examples, tags, hints, and solutions
- Python editor with in-browser execution powered by Pyodide (internet required on first load)
- Run a sample test, mark problems solved, and track progress
- Learn tab with short lessons and quick checks
- Roadmap tab, search, filters, and local device progress persistence

## Run locally
1. Install Node.js LTS.
2. Extract this folder and open a terminal inside it.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

The Python runtime loads from a CDN and needs an internet connection. Progress is saved in this browser's local storage. This starter runs the first sample test for each problem; it is not a full hidden-test judging system like LeetCode.
